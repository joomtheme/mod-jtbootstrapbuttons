JT Bootstrap Buttons

Joomla site modülüyle bir veya daha fazla Bootstrap 5 butonu oluşturun. Renk, outline, boyut, hedef pencere, tam genişlik, pasif durum, hizalama ve buton aralığı gibi tüm seçenekleri destekler.

Installation

Joomla kurulumu

  1. Releases sayfasından son ZIP paketini indirin.
  2. Joomla Administrator panelinde System → Install → Extensions alanına gidin.
  3. ZIP paketini yükleyin.
  4. Content → Site Modules bölümünden JT Bootstrap Buttons modülünü açın.
  5. Butonları ekleyin, modül pozisyonunu seçin ve yayınlayın.
